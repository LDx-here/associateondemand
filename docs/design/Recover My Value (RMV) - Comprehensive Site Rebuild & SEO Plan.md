# Recover My Value (RMV) - Comprehensive Site Rebuild & SEO Plan

**Author:** Manus AI
**Date:** April 28, 2026
**Project:** Recover My Value (RMV) / Lightship

## 1. Executive Summary

This document outlines a comprehensive plan to transform recovermyvalue.com from its current Squarespace-based property damage focus into a powerful, SEO-optimized, dual-pathway client intake platform for Personal Injury and Immigration law. The core recommendation is to rebuild the website using the custom Next.js/FastAPI stack, integrating it seamlessly with the broader Recover My Value (RMV) "Autonomous Law Firm" ecosystem. This strategic shift will enhance lead generation, improve user experience, and provide the necessary technical foundation for advanced AI integrations.

## 2. Key Components of the Plan

### 2.1. SEO Audit & Site Analysis

An in-depth analysis of the existing recovermyvalue.com site revealed its strengths in niche focus (property damage) but significant weaknesses in targeting Personal Injury and Immigration keywords. The current Squarespace platform limits advanced SEO and integration capabilities required for RMV's vision. Opportunities exist in expanding keyword targeting, developing a robust content marketing strategy, implementing advanced schema markup, and building a stronger backlink profile.

### 2.2. Dual-Pathway Client Intake Design

The new website will feature a clear, intuitive dual-pathway client intake system. Prospective clients will be guided to distinct sections for Personal Injury or Immigration, each offering tailored intake questions and information gathering. This system will integrate seamlessly with the RMV AI Receptionist and Advanced Intake & Scheduling Module, ensuring efficient lead qualification and routing to the appropriate legal professionals.

### 2.3. Content Strategy for Dual-Pathway Intake

A comprehensive content strategy will be implemented to attract and engage clients for both Personal Injury and Immigration. This includes extensive keyword research, development of content pillars for each practice area (e.g., accident guides, visa categories), and a mix of content types (service pages, blog posts, FAQs, video content). The strategy emphasizes on-page SEO, social media distribution, email marketing, and local SEO to maximize organic visibility and lead generation.

### 2.4. Platform Recommendation: Custom Next.js/FastAPI Stack

It is strongly recommended to rebuild the RMV website using the custom Next.js/FastAPI stack. Squarespace, while user-friendly for basic sites, is fundamentally incompatible with the advanced, AI-driven, multi-tenant, and highly integrated vision for RMV. The custom stack provides unparalleled flexibility, scalability, and integration capabilities, allowing for the seamless implementation of RMV's unique UI/UX, AI agents, and complex legal logic. This also ensures a consistent development environment for Cursor across both web and mobile platforms.

### 2.5. Updated Technical Architecture & Cursor Prompts

The RMV Technical Architecture has been updated to reflect the decision to rebuild the website on the custom Next.js/FastAPI stack. This includes modifications to the frontend section to explicitly mention both web and mobile platforms, and updates to the APIs and Integrations section to include calendar APIs, email service providers, and Retell AI/Zapier. The Cursor Execution Guide and initialization prompts have also been updated to incorporate this unified development approach, providing Cursor with all necessary context for building both the web and mobile components of RMV.
