# Firm ops — intake checklist

**Cite:** Professional conduct (conflicts, competence, communication); Office Keeper Ch. 3 adapted for RMV immigration practice
**Practice areas:** Firm operations | Intake

## What this element requires
- Conflicts check **before** substantive consult (names, aliases, opposing parties, petitioning relatives, employers)
- Capture immigration posture early: entries/exits, status, prior apps, criminal, fraud/USC claims
- Identify goals + realistic pathways (AOS / consular / relief / not eligible)
- Engagement letter / fee agreement signed; scope clear (what is / isn’t included)
- Collect ID, status docs, prior receipts, court dispositions

## Facts that prove it
- Conflict search result saved to matter
- Intake sheet: biographic, family tree, timeline, prior counsel
- Signed retainer + fee schedule
- Document request list with due dates

## Common pitfalls
- Starting work before conflict clearance
- Missing criminal / false-claim questions that later sink AOS
- Vague scope → disputes over appeals, RFEs, family derivatives

## Sample language pointers
- Use structured intake fields that map to assessment facts
- End consult with written next-steps + document list
