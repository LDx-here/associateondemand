# Firm ops — calendaring & deadlines

**Cite:** Office Keeper Ch. 4 (calendaring / conflicts); EOIR / USCIS deadline practice
**Practice areas:** Firm operations | Removal | Benefits

## What this element requires
- Dual calendaring: primary + backup for hard deadlines (RFE, appeal, IJ filing, biometrics, interview)
- Immigration-critical dates: authorized stay end; UL presence thresholds; conditional residence / I-751 window; one-year asylum clock; NTA hearing
- Conflict check integrated with new matter opening
- Ticklers for receipt notices expected, FOIA follow-ups, Visa Bulletin checks

## Facts that prove it
- Calendar entries with matterId + responsible attorney
- Deadline source document linked
- Confirmation of backup calendar owner

## Common pitfalls
- Single-point-of-failure personal calendar only
- Counting deadlines from wrong trigger (receipt vs decision vs service)
- Missing derivative children’s aging-out dates

## Sample language pointers
- “Deadline = [date] / trigger = [event] / responsible = [name] / backup = [name]”
