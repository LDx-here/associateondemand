# Firm ops — file organization

**Cite:** Office Keeper Ch. 3–4 (file systems, naming, closing); adapt to AOD matter IDs
**Practice areas:** Firm operations | Records

## What this element requires
- One matter ID = one digital file tree; avoid duplicate “working copies” outside CMS
- Naming: `YYYY-MM-DD_doc-type_short-desc.ext` (or firm standard)
- Subfolders: intake/, petitions/, evidence/, correspondence/, court/, billing/
- Save email/PDFs into the matter — not only personal inboxes
- Closing: final accounting, return/retain originals per policy, closing letter, retention schedule

## Facts that prove it
- Matter folder matches AOD matterId
- Index of key filings with receipt numbers
- Closing checklist completed + retention end date

## Common pitfalls
- Version chaos (“final_v7_REAL”)
- Evidence only on staff laptop / WhatsApp
- Closing without trust reconciliation

## Sample language pointers
- Prefer searchable filenames over nested deep trees
- On close: “open items zero; trust balance zero; retention = [date]”
