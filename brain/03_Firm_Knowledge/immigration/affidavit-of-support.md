# Affidavit of support (I-864)

**Cite:** INA § 213A; 8 CFR § 213a; Form I-864 / I-864W / I-864A
**Practice areas:** Family | AOS | Consular | Public charge interface

## What this element requires
- Most family-based immigrants need a sufficient Form I-864 sponsor
- Income generally ≥ **125%** of Federal Poverty Guidelines (100% for active-duty sponsors of spouse/children — verify current instructions)
- Assets may supplement in some cases; household members via I-864A; joint sponsor if needed
- Sponsor must be USC/LPR (or certain qualifying sponsors) domiciled in U.S.; enforceable support contract
- Exemptions / I-864W in limited categories (e.g., some 40-quarter SSA credit cases, self-petitioning widows/VAWA — confirm current eligibility)

## Facts that prove it
- Tax returns / W-2 / pay stubs matching I-864 figures
- Household size calculation (including intending immigrants)
- Assets docs → ownership, liquidity, valuations if used
- Joint sponsor package if primary insufficient
- Domicile evidence if sponsor abroad temporarily

## Common pitfalls
- Wrong household size → under-income finding
- Using outdated poverty guidelines
- Missing tax transcripts when returns look inconsistent
- Assuming employment-based cases always need I-864 (usually not)

## Sample language pointers
- Show poverty guideline year + math in a short table
- Flag joint-sponsor need early in strategy memo
