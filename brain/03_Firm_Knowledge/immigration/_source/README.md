# Source materials (local only)

Put copyrighted immigration treatises / book PDFs here for Cursor conversion.

- **Do not commit** large PDFs or full book scans (gitignored: `*.pdf`, `*.epub`, `*.mobi`).
- After conversion, keep the master book offline or in this folder locally; ship only curated `.md` excerpts one level up.
- Conversion output goes in `../` (e.g. `aos-discretionary-checklist.md`), never as one giant dump.
