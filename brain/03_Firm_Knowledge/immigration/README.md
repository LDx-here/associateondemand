# Immigration knowledge excerpts

Drop **short markdown checklists and chapter summaries** here (`.md` only). Agents load these into prompts (capped ~4–6k characters).

## Do

- Element checklists (e.g. I-485 discretionary factors)
- 1–3 page chapter summaries with controlling cites
- RMV house playbooks in plain text

## Do not

- Whole-book PDFs (not ingested)
- Scanned images without OCR text
- Client PII or sealed materials

Prefer uploading **style samples + short snippets** to `/templates#firm-memory` for live prod drafting. Keep the master book offline or in this vault for humans; extract excerpts here when you want agents to see them.
