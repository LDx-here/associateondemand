# Asylum bars & withholding distinctions

**Cite:** INA §§ 208(a)(2), 208(b)(2), 241(b)(3); 8 CFR §§ 208.13–.16, 1208.16–.18
**Practice areas:** Asylum | Withholding | CAT

## What this element requires
- Screen bars early: persecutor; security danger; terrorist activity; particularly serious crime; serious nonpolitical crime abroad; firm resettlement (asylum)
- Aggravated felony = particularly serious crime for **asylum**; for **withholding**, AF with ≥5-year sentence is particularly serious
- Asylum is discretionary; withholding/CAT are mandatory if eligibility met (higher burden for withholding)
- Firm resettlement bars asylum, not withholding
- One-year deadline is a filing bar with limited exceptions

## Facts that prove it
- Criminal history → AF / PSC analysis
- Third-country status → residence offers, permanent resettlement facts
- Security / persecutor allegations → roles, timelines
- Filing clock → arrival, status, trauma, counsel access

## Common pitfalls
- Stopping at asylum denial without evaluating withholding/CAT
- Missing firm resettlement facts from prior safe-third residence
- Assuming every AF bars withholding

## Sample language pointers
- Checklist bars before merits deep-dive
- Explicitly state which protections remain if asylum is barred
