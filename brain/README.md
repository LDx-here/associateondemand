# Obsidian / markdown “Legal Brain” (deposit guide)

Until the automated ingestion agents land (Phase 3), **you still drop information here**.

## Recommended layout

```
00_Templates/        Final memo / email / motion shells you trust
01_Cases/            One folder per matter (AOD-XXX-ShortName/)
02_Research/         Articles, memos not tied to a single client yet
03_Firm_Knowledge/   Playbooks + “accepted vs rejected” feedback logs
```

## Case folder minimum viable pattern

Inside `01_Cases/<matter>/`:

```
00_Overview.md          Status, deadlines, posture in plain English
01_Intake/              Facts as they arrive
03_Procedural_History/  Filings/hearings (even rough timelines)
07_Strategy/            What you're trying vs what you've ruled out
10_Next_Steps/…         Follow-ups (“call client”, “pull State Dept 2024+2023…”)
decisions-log.md (optional shortcut) Mirrors later correction pipeline manually
```

**Rule of thumb:** if it smells like CRM data (deadlines/tasks), it will migrate to **Airtable in Phase 1–2**. If it smells like prose + narrative, Obsidian stays the home.
